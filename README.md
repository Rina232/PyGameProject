#  Космическая Оборона 

Динамичная космическая аркада, разработанная на языке Python с использованием библиотеки PyGame. Игроку предстоит управлять боевым космическим кораблем, уничтожать метеориты и астероиды, а также искусно уклоняться от космических препятствий.

## Как запустить игру

Для запуска игры вам не нужно устанавливать Python или дополнительные библиотеки. Всё уже собрано в один исполняемый файл.

1. Склонируйте репозиторий.
2. Распакуйте файлы в отдельную папку.
3. Найдите файл `Космическая_оборона.exe` в корневой папке.
4. Дважды кликните по файлу для запуска.

## Управление

* **Стрелки на клавиатуре / WASD** — передвижение космического корабля.
* **Пробел (Space)** — стрельба по астероидам.
* **Esc** — пауза / выход в главное меню.

## Технологии

**Язык программирования:** Python 3
**Графическая библиотека:** PyGame
**Сборка проекта:** PyInstaller (для создания `.exe` файла)

## Разработчикам

Если вы хотите изменить игру или запустить её напрямую через код, вам понадобятся:

1. Установленный Python 3.x
2. Установленная библиотека PyGame:
   ```bash
   pip install pygame
   ```
3. Запуск главного скрипта:
   ```bash
   python main.py
   ```
